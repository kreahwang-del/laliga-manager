## □ 팀원과 관점 (모두 Playwright로 모바일 화면 390×844를 열고 사람처럼 직접 조작)
| 팀원 | 누구처럼 플레이하나 | 주로 보는 것 |
|---|---|---|
| 입문자 | 축구 매니저 게임을 처음 해 보는 캐주얼 유저 | 첫 10분, 튜토리얼, 용어 이해, 어디서 막히고 그만두고 싶어지는지 |
| 매니저 마니아 | FM을 수백 시간 해 본 하드코어 유저 | 경기 결과·스탯·이적료·연봉의 사실성, 전술이 결과에 미치는 영향, 3시즌 이상 장기 플레이의 지루함·밸런스 붕괴 |
| 과금·광고 민감 유저 | 무료로만 끝까지 해 보려는 유저 | 광고 빈도·위치, 유료 없이 사다리를 올라갈 수 있는지, Pay-to-win 느낌 |
| 꼼꼼한 QA | 일부러 이상한 조작을 하는 테스터 | 연타, 뒤로가기, 앱 중단·재시작, 저장 꼬임, 화면 깨짐, 콘솔 오류, 느려짐 |

## □ 진행
- ㅇ 1단계: 각자 정해진 시간 동안 플레이 → `work/06_베타테스트/BT<n>_<팀원>.md`
  - 플레이 기록(무엇을 했는지), 스크린샷 `work/06_베타테스트/BT<n>_screens/`, 콘솔 오류 로그
  - 끝에 5점 척도 평가: 재미, 이해하기 쉬움, 사실성, 공정한 과금, 안정성 + 한 줄 총평
- ㅇ 2단계: 팀원끼리 직접 메시지로 의견 충돌 조정
  - 예: 입문자 「정보가 너무 많음」 ↔ 마니아 「세부 스탯이 더 필요」 → 기본/상세 보기 분리 같은 합의안 도출
  - 같은 결함을 여러 명이 찾았으면 하나로 합치고 재현자 수를 표기
- ㅇ 3단계: 팀장이 `work/06_베타테스트/BT<n>_종합.md`로 정리
  - 「결함(담당 에이전트에 바로 넘김)」 / 「개선 합의안」 / 「사용자 판단 필요」로 나눔
  - 팀원별 점수표와 출시 가능 여부 의견(가능 / 조건부 / 불가)
- * 수정 반영 → 재검증 왕복은 2회까지. 그래도 남는 문제는 「사용자 판단 필요」로 올림

## □ 지적 형식 (항목마다)
- ㅇ 위치: 화면·버튼·시즌/경기 시점
- ㅇ 재현 절차 → 기대 결과 → 실제 결과 → 증거(스크린샷·로그 경로)
- ㅇ 등급: 치명(진행 불가·저장 손상) / 높음 / 보통 / 낮음(취향)
- ㅇ 개선 요청이면 바꿀 방향까지 제시

## □ 규칙
- ㅇ 빌드 사본으로 플레이 → `handoff/`·`src/` 원본은 건드리지 않음
- ㅇ 실명·실제 구단을 연상시키는 요소가 보이면 등급과 무관하게 바로 보고(출시 차단 사유)
- ㅇ 의견은 플레이한 근거(기록·스크린샷)가 있는 것만 → 추측성 의견은 「추정」으로 표시
