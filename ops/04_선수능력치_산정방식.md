# 월드 사커매니저 — 선수 능력치 산정 방식 (2026-11-04 정리)
근거: 프로젝트 문서 `라리가매니저_설계정리`·`WSM_진행현황`, dev 브랜치 소스(`src/app/0070_growth.js`, `src/app/0020_util.js`)

## 1. 능력치 구성 (20점 척도)
- 필드 10개
  - 기술: 슈팅, 패스, 드리블, 크로스, 태클
  - 정신: 위치선정, 침투(오프더볼)
  - 신체: 공중볼, 속도, 체력
- 골키퍼 전용 4개: 선방, 공중장악, 스위핑, 배급
- 파생: 침착성(comp), 힘(str), 프리킥(fk), 페널티(pen) — 위 항목과 전체 수준으로 계산(10항 참고)
- OVR(종합): 화면 표시용 점수(예: 70~94). 경기 엔진은 세부 능력치를 직접 쓰며, 속도·침착성·힘은 격차가 지나치게 벌어지지 않게 압축해서 반영(talV·talK)

## 2. 원자료
- Transfermarkt 기반 Kaggle 데이터셋(davidcariboo/player-scores): 선수 정보, 시장가치 이력, 출전·이적 기록, 경기 명단(2026년 7월 초까지)
- FBref 5대 리그 기록: 2024-25(xG·xA·드리블·수비 등 267개 항목), 2025-26·2026-27(기본 102개 항목, xG 없음)
- EA FC(26·27) 선수 데이터: 보정과 5대 리그 밖 선수에 사용
- 위키백과: 2026-27 소속 변경 반영(v247)
- 실제 데이터에 위 출처가 섞여 있음 → 상용화 때 권리 문제로 가명 데이터로 교체 예정

## 3. 5대 리그 선수 — '우리 추정 + FC 보정'
1. 틀 만들기: 2024-25 세부 기록으로 항목별 능력치 기본 틀
2. 최근 폼 보정: 2025-26·2026-27 기록
3. 기록이 약한 항목(드리블·속도 등): 관련 지표·포지션·나이로 추정
4. 기준 OVR: 시장가치·나이·리그 출전 비중으로 추정
5. 편향 보정: FC 매칭 선수로 그룹별 평균 차이(우리 추정 − FC 변환값) 계산 → 그 85%를 뺌
   - 그룹: 리그×나이대×출전대×GK, 표본 15명 미만이면 상위 그룹
6. 척도 맞추기: FC 점수 → 20점 척도(약 ÷4.2), 겹치는 선수 1,786명으로 분위수 대응표(같은 순위 = 같은 점수)
7. 5대 리그 기록이 없는 선수: 시장가치 + 포지션 기본 틀

## 4. 5대 리그 밖 선수 (포르투갈·네덜란드·튀르키예·브라질·K리그·J리그 등)
- 처음엔 FC 값을 그대로 썼으나, 사용자 지적으로 5대 리그와 같은 방식으로 통일(2026-09-28)
  1. 기준 OVR: 시장가치·나이·출전 비중
  2. 편향 보정: FC 매칭 2,360명 기준, 85% 차감
  3. 세부 능력치: FC 변환 프로필을 보정 OVR 수준으로 평행 이동(속도·체력·GK 4항목은 FC 70% + 우리 30%)
  4. 기록 반영: 2025 리그 골·도움(90분당, 900분 이상, 포지션군 백분위)으로 슈팅 ±1.5, 패스 ±1.0
- FC에 없는 860명(J리그 전체, 브라질 일부): 같은 보정 OVR + 포지션 템플릿(est=1)
- 라리가2 496명·유럽 7개 리그 추가 1,697명: FC 세부 능력치를 공통 분위수 대응표로 변환

### 척도 환산
- 세부 능력치 1점(20점 척도) ≈ OVR 4.15점 (EA FC 약 4.2점 ≈ 20점 척도 1점)
- 실제 선수의 OVR은 데이터에 처음부터 있는 값(3~4항 방식)
- 게임 진행 중: 세부 능력치 변화량을 포지션 가중치로 평균 × 4.15 → OVR에 더함(40~95 범위, 소수점 보관)

### 새로 만드는 선수 (유스·보충·추정)
- OVR을 먼저 정함(유스는 잠재력 등급·나이로)
- 기준값 Q = (OVR − 40) ÷ 54 × 13 + 3 → OVR 40이면 3점, 94면 16점
- 필드 10개 = Q + 포지션 오프셋(OFF10) + 강점 보너스 + 무작위 ±1
  - 오프셋 예: 공격수 슈팅 +2·침투 +2·태클/위치선정 −5 / 센터백 슈팅 −6·크로스 −5·태클/위치선정/공중볼 +2
  - 강점 3개 무작위, 각 +2~4
- 골키퍼 4항목 = Q + 1 ± 1.5 (필드 선수는 1)
- 파생: 힘 = 공중볼×0.6 + Q×0.3 / 침착성 = Q − 2 ± 1.5 / 프리킥 = 크로스×0.6 + 슈팅×0.3 / 페널티 = (슈팅+침착성)÷2
- 시장가치 = 10^(5 + (OVR−45)×3.3÷47) × 잠재력 여유 × 나이 계수, 연봉 = 가치 기준의 12%
