## 1. 어린 선수 의무
- **K리그1 U22(명단 20)**: 1023에서 `teamFor` 래퍼 — KR 구단만, `xi+bench` 중 U22(시즌-22년 이후 출생, △) 수 k 계산 → AI는 벤치 최약체를 elig·부상 없는 U22로 2명까지 교체(외국인 m5 넘지 않게 isFor 아닌 선수 우선), 그래도 k<2면 `bench.length=9-(2-k)`로 잘라 19·18명
  - 사용자: `teamFor(mine)` 벤치도 같은 함수로 맞춤. 단 **0110 `benchList()`가 선수단 전체를 교체 후보로 씀** → 벤치 인원 규정(9/12/7 포함)이 사용자에겐 지금도 적용 안 됨. KR(또는 전체)에서 `benchList`를 `M.m.T[M.me].bench` id 집합으로 제한해야 규정이 의미 있음(전체 적용은 UX 변화 큼 → KR만 먼저 권장)
  - 데이터: KR 12구단 중 5구단이 U22 1명뿐 → 19명 명단이 자주 나옴(의도대로)
- **리가MX 1,170분**: 출전 시간 데이터 **이미 있음** — `S.ps[id].mins`(0060 applyMatch counts=true·0200 fastMatch lgM에서 리그 경기만 누적, newSeason에 0으로). 다른 리그 엔진 경기(0620 eaApply)도 applyMatch 경유라 AI 구단도 집계됨
  - 경기마다 훅 걸지 말 것(결과가 비동기 늦게 반영됨 — 0620 eaLateHook). **점검 시점에 지연 계산**: `mxYMin(c)=Σ 현재 선수단(임대 온 선수 포함) 2004년 이후 출생 q.mins − q.mxOff`
  - 시즌 중 MX 구단으로 온 선수는 `completeTransfer` 래퍼에서 `q.mxOff=q.mins` 기록(이전 구단 출전분 제외)
  - 감점 시점: 1010 `lfPoTick` 래퍼 — 아페르투라 정규 17라운드 결과가 다 찬 첫 호출(리기야 시드 배정 **전**)에 1회 판정(`S.mxChk[season].A`)
  - 진행 안내: 사용자 MX 구단이면 전술 탭/순위 화면에 "U22 출전 812/1,170분" 표시(같은 함수 재사용)
- **사우디 U21 외국인 리그 출전 금지**: 1020 `elig(p,c)` 래퍼 1곳 → 사용자(canUse)·AI(teamFor squadOf 필터) 동시 적용. 조건: SA·isFor·출생 ≥ 시즌−20. 1군 외국인 10명 집계(forCnt)에서도 빼야 몫 규정과 충돌 없음. 데이터상 구단당 0~3명 → 영향 작음
- **튀르키예 2006년 이후 자국 선수 명단 밖**: 1022 `regEx(p,c)` 래퍼 — TR이면 `출생 ≥ 시즌−20 && !isFor` 도 등록 인원 제외. `LGR.TR.reg=28`

## 2. 임대 한도

- 적용 지점

  - 사용자 받기: 0310 `clubRespond` 래퍼(`o.loan`일 때 `{k:'no',msg}`)
  - AI: 임대 실행 4곳에 조건 1개씩 추가 — 0430:105 aiLoanWeek 후보 B 필터, 0620:181 정리 임대, 0600:194 마감 임대, 1014:33 aiSqTrimDay(`quotaOK` 옆)

## 6. 성능 위험·회피
- teamFor: 모든 리그 매 경기 2회(라운드당 수백 회, 미리 계산 eaPrefetch 포함) → 래퍼 첫 줄에서 `lgRaw(c)` 대상 리그 아니면 즉시 반환. 래퍼 안에서 regList·forCnt·S.ps 스캔 금지
- lgMoveOK: 이적시장 중 AI 후보 루프(0600:28 구단×후보) 안에서 호출 → 국적·임대·MLS 집계는 O(1) 캐시 필수(구단당 하루 1회 계산)
- S.ps 전체 스캔(수만 건)은 LOUT 루프 1회로 통합, 후보마다 스캔 금지
- 워커(postMessage)로 넘기는 T에 큰 객체 추가 금지 — 벤치 배열만 조정
- MX 출전 시간: 경기 훅 없이 점검 시 1회 지연 계산(18구단×30명)
- 저장 용량: S.lnS·S.mxChk·S.penS만 추가(시즌 넘길 때 지난 시즌 삭제)
