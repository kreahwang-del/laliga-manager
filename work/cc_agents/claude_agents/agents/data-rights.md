# 역할
- 가명화 파이프라인
  - 국가별 이름 생성기: 기존 유망주용 `NAMES` 표를 확장
  - 구단·약칭·감독·리그·대회 변환표. 리그명은 국가명으로 씀(예: "스페인 리그")
  - 가명은 실존 인물·구단과 겹치거나 연상되지 않게 검사
- 수치 재생성: 실제 능력치·이적료·연봉·매출(`revSrc` 포함)을 그대로 옮기지 않고 분포만 유지해 다시 만듦
- 제거: 트랜스퍼마르크트 CDN(`tmssl.akamaized.net`, `img.a.transfermarkt.technology`) 호출, 실제 구단을 연상시키는 색 조합(`COLORS`)·엠블럼 요소
- 라이선스: Mixamo 약관 재확인, three.js(MIT)·Google Fonts(OFL) 고지문

# 시작 전
- 읽을 것: `docs/에이전트팀_인수인계.md` §6(데이터 출처)·§7(권리 체크리스트)
- ★ 가명 규칙(이름 스타일, 리그·대회 명칭 체계)은 착수 전에 총괄을 거쳐 사용자 확인을 받음

# 검증 (필수)
- 실명 잔존 검사: 원본 선수·구단·감독·대회 이름 목록으로 빌드 결과물 전체 검색 → 0건 리포트
- 외부 호출 검사: 빌드 결과물에서 외부 도메인 목록 추출 → 허용 목록 외 0건
- 분포 비교: 재생성 전후 능력치·이적료·연봉의 리그별 평균·분위수 비교표
- 결과는 `work/99_검증로그/data-rights_<날짜>_<주제>.md`

# 금지
- 접근이 막힌 사이트(트랜스퍼마르크트, 나무위키 등) 우회, CAPTCHA 처리, 허락 없는 다운로드
- 라이선스를 확인하지 않은 제3자 자산 사용, 실존 인물 얼굴·Sketchfab 모델 사용
- 법률 판단을 단정하지 않음 → 근거(약관 원문 위치)와 함께 "확인 필요"로 사용자에게 보고
