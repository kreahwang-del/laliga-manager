# 월드 풋볼매니저 앱 아이콘 시안 (B+ 중계방송 그래픽형)

## 공통
- 바탕 #0A0B0D + 135° 사선 무늬(흰색 5%) + 옅은 사선 면 1개
- 강조 #F5D547(노랑), 보조 #46D6A3(초록)·#E5484D(빨강)·#5AB8F5(파랑)
- 글자는 Big Shoulders Display 굵은 압축체 느낌을 직접 다각형으로 그린 것(12° 기울임) → SVG에 서체·`<text>` 없음, 서체 라이선스 의존 없음
- 엠블럼·방패·별·리그 로고 모티브, 특정 구단 색 조합 없음
- 파일 규칙(시안별 optN_)
  * `optN_icon.svg` : 단일 원본(적응형 캔버스 가운데 288px 영역을 잘라 512로 출력)
  * `optN_512.png` / `optN_192.png` / `optN_48.png`
  * `optN_fg.svg`·`optN_fg_432.png` : 적응형 전경(투명 배경)
  * `optN_bg.svg`·`optN_bg_432.png` : 적응형 배경
- `preview_all.png` : 어두운·밝은 홈 화면, 원형·둥근사각 마스크, 96/48px 비교 + 안전 영역(지름 264px) 확인
- `src/` : 재생성 스크립트(gen.py → SVG, render.js → PNG[sharp], preview.py → 미리보기)

## 시안 1. 스코어버그형 (opt1)
- 구성: 노랑 사선 절단 띠 + 검정 "WFM" + 흰 시계 태그 + 빨강 LIVE 점 + 초록 확률 막대
- 장점: 앱 홈·경기 화면 스코어버그와 가장 직결, 중계 콘셉트가 즉시 읽힘
- 약점: 48px에서 "WFM" 글자는 읽히나 획 사이가 좁음, 요소 수 많음. 띠 양 끝은 안전 원 밖으로 일부 나감(의도된 잘림, 글자는 안쪽)

## 시안 2. 기호형 (opt2)
- 구성: 노랑 공(검정 오각 패널) + 왼쪽 초록·파랑·흰 사선 속도선(전술판 화살표 겸 팀 색 띠) + 빨강 LIVE 점(링)
- 장점: 글자 없음 → 다국어·소형 크기에 강함, 축구 게임임이 즉시 전달
- 약점: 축구공 자체는 흔한 모티브라 장르 내 차별성 낮음

## 시안 3. 글자형 (opt3)
- 구성: 큰 노랑 이탤릭 "W" + 사선 절단(바탕색 틈) + 하단 흰·초록 사선 바
- 장점: 가장 단순·강한 실루엣, 48px에서도 선명, 브랜드 자산으로 키우기 좋음(스토어 그래픽·스플래시에 재사용)
- 약점: 축구 연상은 하단 바·색에만 의존 → 스토어에서는 게임명·스크린샷과 함께 보완 필요

## 추천 순위
1. **시안 3(글자형)** — 48px 판독성 최상, 원형·둥근사각 어느 마스크에서도 무게중심 안정, 요소가 적어 B+ 사선 절단이 가장 또렷하게 드러남
2. 시안 1(스코어버그형) — B+ 콘셉트 전달력은 최고이나 소형에서 정보 과밀
3. 시안 2(기호형) — 가독성은 좋으나 축구공 모티브의 흔함으로 차별화 약함
