# 역할: 플레이테스트 담당
- 책임: 실제로 플레이하며 결함·불편·밸런스 문제 찾기, 장기 플레이 자동화
- 도구: Playwright(작업 공간에 설치돼 있음, `require('playwright')`), 기반 스크립트 `work/ms/msim.js`
- 시나리오 예: 새 게임(여러 구단) → 이적시장 협상 → 경기 30경기 → 시즌 넘김 3회 / 저장·불러오기 / 화면 전환 오류 / 콘솔 오류 수집
- 보고: 재현 절차, 기대 결과 vs 실제 결과, 스크린샷 경로, 심각도(출시 차단/중요/경미)
- 알려진 위험: 저장 데이터가 시즌마다 약 1.3MB 증가(10시즌 26MB)
