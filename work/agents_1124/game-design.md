# 게임 설계 의견 — 리그별 별도 규정 4묶음 (2026-11-24, game-design)

## 0. 원칙(v295 원칙 유지 + 보강)
- 처리 방식 4가지 중 하나로만 정함: **막기**(이유+해결 버튼) / **자동 맞춤**(알림 필수) / **벌점**(단계 경고 후) / **안내**(처벌 근거 없는 규정)
- 자동으로 바꾼 것은 반드시 toast 또는 inbox로 알림 — 몰래 바꾸지 않음(기존 sqrAutoFix 방식)
- 사용자·AI 같은 규정. AI는 "규정을 어기지 않게 미리 고르는" 쪽으로, 벌점은 AI에도 똑같이 적용하되 AI가 실제로 맞는 경우는 드물게
- 화면 정리: tacView 상단 규정 상자가 이미 긴 문장(sqrRuleTxt) → **칩 묶음으로 압축**
  - 예) `외 4/5 ✓` `U22 2/2 ✓` `교체 5` `MX 유스 640/1170분 ⚠` — 모두 ✓면 한 줄, ⚠·✕만 색 표시, 누르면 상세 시트
  - 해당 리그 규정 칩만 표시(다른 리그 규정 노출 금지)

## 2. 강한 벌점(리가MX 승점 −3) 경고 방식
- 기존 게임에 승점 조정 장치 없음 → 새 필드 `S.ptsAdj[c][대회]` + 순위표에 `(−3)` 표기, 감점 근거 툴팁
- 경고 4단계(짜증 최소, 놓치지 않게)
  1. 대회 시작: inbox 1회 + 칩 `유스 0/1170분`(목표 페이스 69분/경기)
  2. 페이스 미달: 칩 노란색 + 경기 전 화면에 `+1명 넣기` 버튼(같은 포지션 2004+ 최고 OVR로 교체, 실행 취소 가능)
  3. 위험(남은 경기×90 < 남은 필요 분×1.2): 킥오프 직전 확인 시트 1회 — `자동으로 넣고 시작 / 그대로 시작`. 같은 경기에서 재표시 금지
  4. 불가능 확정 또는 17라운드 후 감점: inbox + 순위표 표시. 감점 실행은 조용히 하지 않음
- 자동 선발(sqrAutoPick)·휴가/자동 진행 시에는 페이스를 지키도록 2004+ 선수를 자동 포함(사용자가 손 안 대면 감점 안 받게)
- 분 집계는 경기 결과 처리 때 구단별 누적(`S.mxMin[c]`)으로 — teamFor·화면에서 S.ps 전체 훑기 금지(v293 끊김 원인)
- 아페르투라·클라우수라 각각 17라운드 기준으로 초기화(클라우수라 기준 △ → 같은 값 가정, '추정' 표기)
- '육성 권리 수입 15% 삭감'은 해당 수입 체계 없음 → 반영하지 말 것

## 3. MLS 연봉 상한·DP와 기존 연봉 한도 합치기
- **두 층으로 분리**: 기존 `CLUBS[c].wageCap`(구단 비용 한도 = 실제 지급 총액, 구단주 돈)은 그대로 + 새 `리그 샐러리캡`(cap hit 합계 ≤ $6.425M) 추가. 영입·재계약은 둘 다 통과해야 함
- cap hit 계산 `mlsHit(c)`: 1군 등록 상위 20명(시니어) 기준
  - 일반 선수: 연봉 그대로, 단 연봉 > 최대 예산($803,125)이면 DP 자리 필요
  - DP(최대 3): cap hit = $803,125, 나머지는 cap 밖(구단 비용 한도에서만 차감)
  - U22 이니셔티브(3~4): 고정 소액 cap hit(예 $200k) — 22세 이하 중 연봉 높은 순
  - 21~30번째·홈그로운: cap 밖
- **DP·U22는 자동 지정**(연봉 높은 순) — 저장 상태 없이 매번 계산 → 세이브 호환 쉬움, 사용자 관리 부담 없음. 수동 지정은 하지 말 것(1단계)
- 화면
  - 재정 화면 wxCard 아래 `MLS 샐러리캡` 카드: cap hit 막대 + `DP 2/3` `U22 3/4` 칩
  - 협상 화면(0510 v160 상자)에 행 하나 추가: `샐러리캡 여유 $x · 이 선수 cap hit $y (DP 자리 사용)` — 넘으면 빨간 문구 + 해결안(판매·방출·DP 자리 비우기)
  - 스쿼드 탭 선수명 옆 `DP`·`U22` 배지(기존 natTag 배지 방식 재사용)
  - 이적 예산↔연봉 한도 전환(wxMove)은 구단 비용 한도만 바꾸고 샐러리캡은 안 바뀐다는 한 줄 안내
- 통화: 게임 단위(€)로 환산해 계산, 표시는 `$6.425M(≈€x)` 병기
- 외국인 자리: 1단계는 구단당 8자리 고정(241/30, SQR.US={h:8}). 자리 거래는 2단계(사용자만 '자리 구매' 버튼, AI 거래 없음) — 지금 하지 말 것
- GAM/TAM 등 할당금 제도는 제외(복잡도 대비 재미 낮음)
- AI: lgMoveOK에 cap hit 검사 추가, AI 예산(aiBudget)은 기존대로

## 4. 기존 세이브·새 게임
- 새 게임: 전부 바로 적용
- 기존 세이브(mig311처럼 `mig312` 1회 안내)
  - 막기류(독일 12·튀르키예·임대·MLS): 지금 선수단은 인정, **새 계약·판매부터** 검사(강제 방출 금지)
  - MLS 기존 초과: cap hit 줄이는 계약만 허용, 늘리는 계약 차단
  - 리가MX 분 집계·감점: **다음 대회(아페르투라/클라우수라)부터** — 진행 중 대회에 소급 감점 금지
  - K리그1·2·사우디: 경기 단위 규정이라 바로 적용 가능

## 5. 위험·하지 말 것
- 성능: 규정 검사는 날짜 캐시·구단 누적값으로(LOUT·LNO_C 방식). teamFor 안에서 S.ps 순회 금지
- AI 붕괴: 독일 12·튀르키예 14 미달 구단이 영입 불가로 선수단 공백 → AI는 '미달이면 자국 선수 우선 영입' 보정 + 초기 DB 미달 구단은 인정
- 밸런스: K리그2 교체 축소가 사용자만 불리하지 않게 AI도 U22 선호 반영
- 하지 말 것: 몰수패·강제 방출, 숨은 자동 변경, 경기 중 교체 불가로 멈추는 상태, 처벌 근거 없는 규정(J1·중국·벨기에)에 벌점, 규정 끄기(sqrCanToggle) 우회 허용
