## 3. 사실성·공정성을 해치지 않는 과금 설계 원칙

| 판매해도 됨 (편의·시간·외형·정보) | 팔지 않음 (결과·능력 직접 구매) |
|---|---|
| 광고 제거, 완전판 해금 | 경기 결과 보정, 승률 버프 |
| 추가 세이브 슬롯, 클라우드 백업 | 선수 능력치 직접 상승, 유료 전용 스타 선수 |
| 상세 분석 리포트(스카우트 보고서·xG·상대 전술 분석) | 이적료·재정 규정 무시권 |
| 경기 하이라이트·3D 시점·리플레이 저장 | 유료 화폐로만 영입 가능한 선수 (Top Eleven 비판 사례 [B4]) |
| 유니폼·엠블럼 꾸미기, 감독 아바타 | 확률형 선수 팩(가챠) |
| 추가 리그 팩, 데이터 에디터 (DLC) | 난이도 사다리 단계 건너뛰기를 유료로만 허용 |
| 시뮬 배속·자동 진행 (시간 단축이지만 결과 동일) | 부상 즉시 회복 같은 경기력 소모품 (New Star·Top Eleven 방식) |

원칙
- ㅇ **같은 입력 → 같은 결과:** 결제 여부가 엔진 계산식에 들어가지 않게 함 (테스트로 확인: 같은 시드, 결제 플래그만 바꿔 결과 일치)
- ㅇ **무과금으로 사다리 끝까지 도달 가능:** Hattrick 「경기 이점은 팔지 않는다」 원칙과 같음 [E1]
- ㅇ **보상형 광고 보상도 편의 위주:** 예) 추가 스카우트 보고서 1회, 이적 협상 재시도 1회, 하이라이트 저장. 경기력 버프는 주지 않음
- ㅇ **확률형 상품 미도입:** 법적 부담(4장)과 사실성 훼손을 함께 피함

### 안 A — 「무료 체험 + 완전판 해금」 (권장)
- 구성
  - 무료: 하위리그 사다리 1~2단계(예: 아시아·유럽 하위리그 3시즌) 전부, 광고 있음
  - **완전판 해금 (일회, 약 ₩5,900~9,900):** 사다리 전 단계, 광고 제거, 세이브 슬롯 추가
  - DLC (선택, 일회): 데이터 에디터, 추가 리그 팩, 감독 아바타·엠블럼 꾸미기 팩
- 광고 배치
  - 보상형: 「스카우트 보고서 추가 1회」 「이적 협상 재시도」 「경기 하이라이트 저장」 — 사용자가 버튼을 눌렀을 때만
  - 전면: 시즌 결산 화면 닫은 직후 1회 (Play 정책 예외 범주 [M4]), 경기 직전·중 금지
- 1인 운영 부담: 낮음 (서버 불필요, 상품 3~5개, Play Billing 비소모성 상품만)
- 위험: 객단가 낮음, 해금 전환율이 낮으면 매출 작음 → 무료 구간의 재미가 핵심

### 안 B — 「하이브리드: 보상형 광고 + 편의 IAP + 완전판」
- 구성: 안 A + 소모성 소액 상품(예: 시뮬 배속 시간권은 피하고, 「상세 분석 리포트 묶음」 등)
- 광고 배치: 안 A + 경기 후 「하이라이트 보기」 보상형, 일일 보상 2배
- 1인 운영 부담: 중간 (소모성 상품 지급·복구, 환불 대응, 광고 보상 지급 실패 처리)
- 위험: 재화를 만들면 결국 경기력 상품 압력이 생김 → 「P2W」 리뷰 위험 [B4]. 오프라인 저장이라 재화 조작(치트)에 취약

### 안 C — 「프리미엄 + DLC」
- 구성: 유료 다운로드(약 ₩6,500~12,000), 광고 없음, DLC(리그 팩·에디터)
- 1인 운영 부담: 가장 낮음
- 위험: 무명 신작의 유료 앱은 유입이 매우 적음. 체험판을 따로 내야 하므로 사실상 안 A로 수렴

### 추천
- **안 A로 출시 → 지표(해금 전환율, 보상형 광고 시청률)를 본 뒤 DLC 추가.** 안 B의 소모성 상품은 출시 후 필요할 때만 검토
- 근거: ① 장르 불만이 P2W·광고 과다에 집중 [B4][C3], ② 호평은 「광고 없는 완전판」 「무과금 완주」 [I1][F1], ③ 사실성 핵심 가치와 충돌 없음, ④ 서버·라이브 운영 없이 1인 운영 가능, ⑤ 가챠 법적 부담 회피

### 결정이 필요한 사항 (사용자 확인)
1. 완전판 가격대와 무료 구간 범위(몇 단계·몇 시즌까지)
2. 시즌 결산 후 전면광고 1회 허용 여부
3. DLC 범위(에디터 판매 시 가명 데이터를 실명으로 바꾸는 유저 편집 허용 여부 → 권리 측면 data-rights 검토 필요)
