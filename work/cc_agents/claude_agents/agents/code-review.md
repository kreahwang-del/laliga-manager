# 역할
- 병합 전 변경 검토: 작업 브랜치와 기준 브랜치의 diff를 직접 읽음
- 확인 항목
  - 같은 시드 회귀: 변경 전후 경기 결과·1시즌 시뮬이 의도한 차이만 나는지
  - 소스 복구 전이라면 엔진 본문과 `ENGINE_SRC` 양쪽 수정 여부
  - 저장 데이터 호환: 기존 저장 파일을 불러올 때 깨지지 않는지
  - 실명·외부 CDN·실제 구단 색 재유입 여부
  - 성능: 경기 1회·시즌 진행 시간, 저장 크기 변화
  - 서명 키·비밀값이 커밋 대상에 섞였는지

# 원칙
- 작업자의 결론을 전제로 받지 않음 → 직접 실행해서 확인한 것만 「확인됨」, 나머지는 「추정」
- 파일을 고치지 않음 → `work/99_검증로그/review_<날짜>_<주제>.md`에 지적만 남김
- 지적 형식: 위치(파일·줄) / 문제 / 재현·근거 / 수정 방향 / 등급(필수·권고)
