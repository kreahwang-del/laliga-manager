기존 원칙(1011 주석, 2026-11-05 결정) 유지 전제: 몰수패·강제 방출 없음 / 영입 전 차단 + 경기 전 자동 맞춤 / AI도 같은 규정 / 시즌 첫 경기 전에만 규정 끄기

## □ 1. 플레이어 부담 줄이기

ㅇ 규정 관리 업무를 '수석코치 위임'으로 처리(기본 켬)
  * 등록 마감(여름·겨울 이적시장 닫히는 날) 3일 전, 받은편지함에 "추천 1군 명단" 1건 → [그대로 확정]/[직접 수정] 2택
  * 위임 켬: 마감일에 추천안 자동 적용 / 위임 끔: 마감일까지 미확정이면 추천안 적용 + 알림
  * 추천 기준: OVR 순 + 포지션 최소(GK 2·DF 6·MF 6·FW 3) + 비EU·HG 충족, 21·22세 이하 면제자는 자동으로 명단 밖 처리
  → 규정이 늘어도 플레이어가 직접 해야 할 일은 '마감 알림 1건 확인'으로 고정

ㅇ 스쿼드 탭 상단 '규정 미터' 1줄(리그에 해당하는 항목만 표시)
  * 예: 등록 23/25 · 비EU 3/3 · HG 7/8(▲부족) · 면제 4명
  * 부족·초과 항목만 색 표시, 누르면 규정 화면(✓ 확정 / '추정' 표시)으로 이동
  * 규정 없는 리그(포르투갈·스코틀랜드·오스트리아 등)는 '등록 n/30'만 → 화면 복잡도가 리그 따라 자연스럽게 달라짐

ㅇ 영입 화면 '등록 미리보기' 배지
  * 협상 전에 결과 표시: [바로 등록] / [비EU 슬롯 사용(마지막)] / [등록하려면 1명 제외 필요] / [21세 이하 면제]
  * 영입 실패 이유를 협상 끝난 뒤가 아니라 검색 단계에서 보여 줌 → 헛걸음 제거

## □ 2. 규정을 전략적 선택으로 바꾸기

ㅇ 비EU 슬롯 = 희소 자원
  * 이중국적(G/nat2.json 3,128명)·EU 국적 선수가 '숨은 가치'가 됨 → 스카우트 보고서에 "EU 여권 보유" 태그
  * 라리가 3명 한도 → "남미 유망주 1명 더 vs 즉시 전력 비EU 1명" 같은 실제 고민 발생

ㅇ 홈그로운 시계(HG 카운트다운)
  * 15~21세 선수에게 "HG까지 1.2시즌" 표시(hgTM.json 재적 일수 기준)
  * 임대 보내면 시계가 멈추는지/흐르는지 표시 → 유스 임대·보유 판단이 선택지가 됨
  * 세리에A·덴마크처럼 "부족분만큼 명단 축소" 리그에서 유스 육성이 곧 전력 → 감독 성장 축('유스 육성형' 평판)과 연결

ㅇ 리그 정체성
  * 튀르키예 14명(4명 2003년 이후)·사우디 10명(2명 2004년 이후) → 젊은 외국인 발굴이 리그 고유 과제
  * 규정 화면에 리그별 '핵심 과제 1줄' 표시(예: EPL "자국 육성 8명 확보", 사우디 "외국인 10명 중 유망주 2명")

ㅇ 사실성 영향: 수치 왜곡 없음(규정 자체가 현실값). 단, AI 구단 전력 분포가 바뀔 수 있어 engine-sim 확인 필요(□5)

## □ 3. 1군 30/보유 40·2군 구조와 난이도 사다리

| 구분 | 아시아·하위 리그(사다리 1~2단계) | 5대 리그(3~4단계) |
|---|---|---|
| 적용 규정 수 | 1~2개(외국인 출전 수 정도) | 3~4개(등록 25·비EU·HG·면제) |
| 2군 역할 | 거의 비어 있음(재정상 보유 25~30) | 유망주 보관·HG 시계·면제자 관리 |
| 플레이어 과제 | 전술·성적으로 평판 쌓기 | 명단 설계·유스 정책 |

ㅇ 규정 수가 사다리를 따라 늘어나는 구조 = 자연스러운 튜토리얼 → 첫 10분에 규정 설명 불필요, 상위 리그로 이직할 때 1회 안내
ㅇ 이직 제안 화면에 "이 리그 규정 요약" 2~3줄 추가 → 이직이 '새 규칙 환경으로의 도전'으로 읽힘
ㅇ 등록 인원 하한 필요(v309 알려진 문제: 일부 구단 1군 11~16명)
  * 제안: 1군 등록 하한 = 22명(면제 대상 2군 소집 가능 인원 포함 시 18명 이상 실가용), AI resAssignAI 마지막 단계에서 하한까지 2군 상위 선수 올림
  * 25명 리그는 1군 상한 25, 30명 리그는 30 → SQMAX를 리그 값으로(OWNMAX 40은 공통 유지)
ㅇ 보유 40은 5대 리그에서만 실제로 부딪힘 → 하위 리그 재정·급여 총액이 이미 제약이므로 추가 장치 불필요

## □ 4. 규정 위반 처리 권장안

| 시점 | 현행(v295·v309) | 권장 |
|---|---|---|
| 영입 검색·협상 | 사용자: 외국인 한도 차면 영입 불가 | 배지로 미리 경고, 협상은 허용(마감 전 정리 가능하므로). 단, 보유 40 초과는 차단 유지 |
| 영입 완료 | 1군 꽉 차면 2군 등록 + 알림 | 동일 + 규정 미터 갱신 |
| 등록 마감일 | 없음 | 미충족 시 추천안 자동 적용(1군→2군 이동, 계약 유지) |
| 경기 전 | 경기 명단 외국인 상한 자동 맞춤 | 동일, 비EU·HG·사우디 경기 명단 8명까지 같은 방식 |
| HG 부족(IT·DK) | 없음 | 현실대로 명단 축소(자동, 미터에 '축소 2명' 표시) |
| 몰수패·강제 방출 | 없음 | 계속 없음 |

ㅇ 3단계 원칙: 경고(미리보기·미터) → 자동 맞춤(마감일·경기 전) → 차단(보유 40·이적시장 밖 영입 등 하드 상한만)

ㅇ 기존 세이브 전환(결정: 다음 이적시장부터)
  * 불러오기 직후: AI 구단만 새 기준 재배정(mig309 방식, 플래그 S.mig310), 사용자 구단은 현 상태 인정
  * 다음 이적시장 열릴 때 받은편지함 1건: "이번 시장 마감일부터 리그 규정 적용, 현재 부족·초과 항목" + 추천 명단
  * 첫 마감일 1회는 위임 꺼져 있어도 확인 창 띄움(조용히 선수가 2군으로 빠지는 일 방지)
  * HG 판정은 세이브 내 이력(재적 일수)으로 재계산, 데이터 없는 생성 선수는 국적 기준 추정 표시

## □ 5. 우선순위 제안

1. 공통 틀 먼저: 리그 규정 데이터 1곳(SQR 확장: 등록 상한·비EU·HG·면제 나이·벤치·경고) + 규정 화면(✓/추정) + 규정 미터 → 이후 리그 추가는 데이터만
2. 경고 누적·벤치 인원(AR·MLS·SC·DK, 벤치 AR·NL 12, FR2 7): 플레이어 부담 0, 엔진만 수정 → 1과 같이 묶어 빠른 성과
3. 등록 25명 + 21·22세 면제 + 등록 마감 추천 명단(EPL·세리에A·라리가·덴마크·사우디) + 1군 하한
4. 비EU 한도(ES 3·FR 4·2부 2): 이중국적 데이터 준비됨, 영입 미리보기 배지와 함께
5. 홈그로운(EPL 8·IT 8+4·DK 8+4·DE local 4) + HG 시계: 표시 부담이 가장 커서 마지막. 독일 국적 12명은 독일 리그에서 거의 항상 충족되므로 검사만 넣고 미터 표시 생략 권장
6. 보류: MLS 해외 선수 자리 거래(리그 241개) → 구단당 8 고정으로 단순화, 거래 기능은 상용판 이후

ㅇ 검증(engine-sim·QA): 새 게임 3시즌 × AI 리그별 상위 5팀 평균 OVR·승점 분포가 규정 전후 크게 달라지지 않는지, 사용자 구단 마감일 자동 적용 후 경기 명단 18명 미만 발생 0건
ㅇ 구현 담당: 규칙·자동 맞춤·AI = engine-sim / 미터·배지·추천 명단 창·이직 화면 요약 = ux-design
