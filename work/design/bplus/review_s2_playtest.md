## 대회 테마 충돌(확인 4)

- 챔스(UCL)·국왕컵 모두 .mth + .bp 동시 적용, 배지·배경 정상, 오류 없음 → 큰 충돌 없음
- 작은 충돌
  - 시계 칩 배경이 대회색(라리가 코랄 #ff4b44)이라 오사수나·바이에른 같은 빨강 팀 띠 바로 옆에서 섞여 보임(rv_m60.png, rv_board_ucl_390.png). 시안은 흰 칩
  - .mth 의 보드 하단 대회색 선(border-bottom)을 .bp 가 0 으로 지움 → 대회 구분 단서가 배지·시계 색만 남음(의도라면 무방)
- 컵 경기 결과 보기·연장/승부차기는 실행하지 않음(서버 부하 제약)

## ③ 개선 의견

- 스코어버그 이름은 CLUBS[].short(3글자) 또는 약칭 + 말줄임으로 — 결함 1·2를 한 번에 해소하고 시안과도 일치
  - 순위(.mrk)는 이름 아래 작은 줄로 되돌리거나(flex-direction:column 묶음) 흐름 줄 옆으로 이동
- 팀 색 충돌 처리: 두 팀 색 차이가 작으면 원정 팀 2색 사용, 글자색은 대비 계산으로
- GOAL 띠를 피치 하단(시안처럼 bottom 16px, 높이 44px, 왼쪽에서 슬라이드)으로 내려 장면 가림 최소화, 선수명은 shortName
- 토스트 색을 앰버 말고 흰/회색으로 바꾸거나 시트 열린 동안 위치를 시트 위로

## 시안 대비 아쉬운 점(우선순위)

1. 스코어버그 구조: 시안은 "약칭 + 점수가 팀 색 블록 안 + 흰 시계 탭" 구조인데 적용본은 정식명 + 중앙 검정 점수판 → 긴 이름 문제의 근원. 약칭 방식으로 가면 가독성·폭 문제 동시 해결
2. 흐름(MOMENTUM): 시안은 구간별 위/아래 막대 그래프 섹션인데 적용본은 4px 단일 막대 → 정보량이 적고 흰 팀이면 안 보임. 시안의 LIVE 점·라운드 표기도 빠짐
3. GOAL 하단 자막: 시안은 피치 하단 로어서드(등번호·시즌 n호·도움)인데 적용본은 피치 중앙 가로 전체 띠 → 장면을 더 가리고 정보는 적음
