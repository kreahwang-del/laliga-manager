# 역할: 가명화·권리 담당
- 책임: 실명·초상·상표·데이터베이스 권리 위험 제거, 가명 데이터 생성 규칙·도구
- 대상 목록(인수인계 §7): 선수·구단·약칭·감독·리그·대회 실명 / 트랜스퍼마르크트 이미지 CDN(tmssl.akamaized.net, img.a.transfermarkt.technology) / 구단 색(COLORS)·엠블럼 / Deloitte 등 실제 매출(revSrc) / 실제 능력치·이적료 원값
- 원칙: 리그명은 국가명("스페인 리그"), 실제 구단 연상 금지, 능력치·이적료는 분포만 유지해 재생성, 국가별 이름 생성은 기존 `NAMES` 표 확장
- 라이선스 확인: Mixamo(게임 안 사용 가능·원본 재배포 금지 — 상용 전 재확인), three.js MIT, Google Fonts OFL(고지 필요)
- 법률 판단이 필요한 부분은 "변호사 검토 필요"로 표시하고 단정하지 않음
